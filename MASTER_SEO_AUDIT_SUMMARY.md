## 🔴 CRITICAL ISSUES (Fix This Week)

### 1. Missing Meta Descriptions (All Pages)
- **Current:** 0 pages have optimized meta descriptions
- **Impact:** Losing 15-20% potential organic CTR
- **Fix Time:** 2-4 hours
- **Priority Score:** 10/10

**Ready-to-Use Examples:**
```html
<!-- Homepage -->
<meta name="description" content="FP&A consulting, fractional CFO, and financial modeling services by Paul Barnhurst. 15+ years experience, CFI faculty, Wharton instructor. Free consultation.">

```

### 2. Privacy Policy Returns 404
- **Current:** Legal page missing entirely
- **Impact:** GDPR/CCPA non-compliance, trust erosion, potential legal risk
- **Fix Time:** 2 hours (use template)
- **Priority Score:** 10/10

**Action:** Create `/privacy-policy` page with:
- Data collection practices
- Cookie usage
- Third-party services (Google Analytics, Calendly, email provider)
- Contact information
- GDPR/CCPA compliance language

### 3. No Service Pages Exist
- **Current:** `/services`, `/consulting`, `/fractional-cfo` all return 404
- **Impact:** Cannot convert traffic to consulting clients
- **Fix Time:** 8-12 hours (create 3-4 core service pages)
- **Priority Score:** 10/10

**Required Pages:**
1. `/services/fractional-cfo` - Strategic CFO leadership
2. `/services/financial-modeling` - Custom models for fundraising/M&A
3. `/services/fpa-consulting` - Process improvement, team building
4. `/services/budgeting-forecasting` - Rolling forecasts, driver-based planning

### 4. No Booking Calendar Integration
- **Current:** Contact form requires 6+ email exchanges to book
- **Impact:** Losing 40-50% of consultation inquiries
- **Fix Time:** 1 hour
- **Priority Score:** 9/10

**Action:**
- Integrate Calendly or similar
- Add "Book Free 30-Min Consultation" CTA to header
- Embed calendar on `/contact` and service pages

### 5. Missing Schema Markup (Critical Types)
- **Current:** Basic Organization schema only
- **Impact:** No rich snippets, missing SERP real estate
- **Fix Time:** 4-6 hours
- **Priority Score:** 9/10

**Required Schema:**
- **Person** (Paul's credentials) - All pages

- **Course** (3+ courses) - Google Course carousel

## Platform-Specific Guidance (Squarespace)

### Adding Schema Markup:
1. Settings → Advanced → Code Injection → Header
2. Paste schema `<script type="application/ld+json">` blocks
3. Use separate blocks for Person, Organization, Breadcrumb (site-wide)
4. Use page-level injection for page-specific schema

### Meta Tags:
1. Page Settings → SEO tab
2. Page Title (60 char max)
3. Page Description (155 char max)

### Calendly Integration:
1. Embed Calendly inline widget on `/contact` page
2. Add Calendly popup link to header navigation
3. Code example provided in technical audit report

### Privacy Policy:
1. Create new page at `/privacy-policy`
2. Use Squarespace privacy policy template
3. Customize for your data practices
4. Link from footer (all pages)
