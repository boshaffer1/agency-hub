- Wharton: "Wharton & Wall Street Prep FP&A Certificate Program"

✅ **USE:**

### 24. Performance Tracking Stack
**Heatmaps show problems, recordings show why, events show what**

🔄 **IMPLEMENT:**
```
Google Analytics GA4:
- Event: CTA clicks (which button, what page position)
- Event: Discount code copies (which code)
- Event: Scroll depth (% of page seen)
- Event: Time on page segments (<1min, 1-3min, >3min)

Hotjar or Microsoft Clarity (free):
- Heatmaps: Where users click
- Recordings: Session replays
- Surveys: Exit intent "Why didn't you enroll?"

URL Parameters:
- Track source: ?utm_source=linkedin
- Track campaign: &utm_campaign=certification_review
- Track content: &utm_content=cta1 (which CTA)
```
