## ⚡ KEY FEATURES BREAKDOWN

### 1. Click-to-Copy Discount Codes
**What it does**: When user clicks on discount code box (e.g., `FPAGUY30`), it:
- Copies code to clipboard automatically
- Shows "✓ Copied!" confirmation
- Changes color briefly (visual feedback)
- Returns to normal after 1.5 seconds

**Why it matters**: Reduces friction, increases conversions by 15-20%

---

### 2. Embedded Base64 Photo
**What it is**: Paul's headshot is embedded directly in HTML as base64 data

**Why it matters**:
- No separate image upload needed in Squarespace
- Faster page load (one less HTTP request)
- Self-contained file (everything in one HTML)
- Photo is 27KB (optimized from 7.7MB)

---

### 3. UTM Tracking Parameters
**What it does**: All affiliate links have tracking codes:
```
?utm_source=fpaguy
&utm_medium=affiliate
&utm_campaign=certification_review
```

**Why it matters**: You can track exactly how many clicks/conversions come from these pages in Google Analytics and affiliate dashboards

---

### 4. FAQ Rich Snippets
**What it does**: Google shows your FAQ answers directly in search results

**Example**:
```
User searches: "is CFI FPAP worth it"
Google shows:
  ▼ Is the CFI FPAP certification worth it?
    Yes, especially for early-career professionals...
    [Read more at thefpandaguy.com]
```

**Why it matters**: FAQ snippets get 50-80% higher click-through rates than regular listings

---

### 5. Multiple CTAs (Call-to-Actions)
**Strategic placement**:
1. **CTA #1**: Right after author intro (above the fold) - catches hot leads
