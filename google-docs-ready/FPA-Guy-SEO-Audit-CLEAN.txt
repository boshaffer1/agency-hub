ISSUE #5: MISSING SCHEMA MARKUP (CRITICAL TYPES)

Current State: Basic Organization schema only
Impact: No rich snippets, missing SERP real estate, weak E-E-A-T signals
Time to Fix: 4-6 hours
Priority: CRITICAL (9/10)

Schema markup provides rich snippets (star ratings, FAQs, breadcrumbs) in Google search results. Can increase click-through rate by 20-30%.

Required Schema Types:

1. Person Schema (All Pages)
Establishes Paul's credentials and expertise
Shows: Job title, credentials, professional affiliations

2. BlogPosting Schema (102+ Articles)
Enables article rich snippets in search
Shows: Author, publish date, reading time, article image

3. Course Schema (3+ Courses)
Enables Google Course carousel feature
Shows: Course title, provider, price, rating

4. ProfessionalService Schema (Service Pages)
Defines service offerings for Google
Shows: Service type, area served, price range

5. FAQPage Schema (Service Pages)
Most impactful - creates expandable FAQ boxes in search results
Shows: Questions and answers directly in Google

6. Breadcrumb Schema (All Pages)
Shows navigation path in search results
Shows: Home > Services > Fractional CFO

How to Implement in Squarespace:
1. Go to Settings → Advanced → Code Injection
2. Add schema code to Header section
3. Use page-level injection for page-specific schema
4. Validate with Google Rich Results Test

Detailed code examples provided in implementation guide.

ISSUE #10: NO CORE WEB VITALS MONITORING

Current State: Performance metrics not being tracked
Impact: Cannot measure or improve page speed and user experience
Time to Fix: 30 minutes
Priority: HIGH (7/10)

Core Web Vitals are Google's page experience signals that affect rankings:

1. Largest Contentful Paint (LCP)
   Measures: Loading performance
   Target: < 2.5 seconds
   Impact: How fast main content appears

2. First Input Delay (FID)
   Measures: Interactivity
   Target: < 100 milliseconds
   Impact: How quickly page responds to user interaction

3. Cumulative Layout Shift (CLS)
   Measures: Visual stability
   Target: < 0.1
   Impact: Unexpected content shifts while loading

How to Set Up Monitoring:

1. Google Search Console (Already Setup):
   • Core Web Vitals report shows real user data
   • Identifies pages that need improvement
   • Shows mobile vs desktop performance

2. PageSpeed Insights:
   • Test any page: https://pagespeed.web.dev/
   • Get specific recommendations
   • See both lab and field data

3. Create Monthly Tracking Spreadsheet:
   Date | Page | LCP | FID | CLS | Mobile Score | Desktop Score | Issues

Action Items:
• Run PageSpeed Insights on 10 key pages
• Document current scores
• Identify top 3 performance issues
• Track monthly to measure improvement

Common Issues to Fix:
• Unoptimized images (too large, wrong format)
• Render-blocking JavaScript
• Excessive third-party scripts
• No browser caching
• Unminified CSS/JS

ADDING SCHEMA MARKUP IN SQUARESPACE


Method 1: Site-Wide Schema (Person, Organization, Breadcrumb)

1. Log into Squarespace
2. Go to Settings → Advanced → Code Injection
3. In the Header section, paste:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Paul Barnhurst",
  "alternateName": "The FP&A Guy",
  "url": "https://www.thefpandaguy.com",
  "jobTitle": "FP&A Expert, Faculty Member & Consultant"
}
</script>

4. Click Save


Method 2: Page-Specific Schema (Service pages, articles)

1. Navigate to the specific page
2. Click page settings (gear icon)
3. Go to Advanced → Page Header Code Injection
4. Paste page-specific schema code
5. Click Save

UPDATING META TAGS IN SQUARESPACE


For Individual Pages:

1. Navigate to the page you want to edit
2. Click page settings (gear icon)
3. Click SEO tab
4. Enter Page Title (60 characters max)
5. Enter Page Description (155 characters max)
6. Click Save


For Blog Posts:

1. Edit the blog post
2. Click Options
3. Find SEO Description field
4. Enter meta description (155 characters max)
5. Page title auto-generates from post title
6. Click Save


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


INTEGRATING CALENDLY


Method 1: Inline Embed (Contact Page)

1. Go to Calendly, get your scheduling link
2. In Squarespace, edit your Contact page
3. Add a Code block
4. Paste Calendly embed code:

<!-- Calendly inline widget begin -->
<div class="calendly-inline-widget" data-url="https://calendly.com/your-link" style="min-width:320px;height:630px;"></div>
<script type="text/javascript" src="https://assets.calendly.com/assets/external/widget.js" async></script>
<!-- Calendly inline widget end -->

5. Save and publish


Method 2: Popup Widget (Navigation Button)

1. Add Calendly popup code to Code Injection (header)
2. Create navigation link with Calendly URL
3. Link opens Calendly overlay on click
