PLATFORM-SPECIFIC GUIDANCE (SQUARESPACE)
═══════════════════════════════════════════════════════════════════════════════

ADDING SCHEMA MARKUP:
    1. Navigate to: Settings → Advanced → Code Injection → Header
    2. Paste schema in <script type="application/ld+json"> blocks
    3. Use separate blocks for Person, Organization, Breadcrumb (site-wide)
    4. Use page-level injection for page-specific schema

UPDATING META TAGS:
    1. Go to: Page Settings → SEO tab
    2. Enter Page Title (60 character max)
    3. Enter Page Description (155 character max)
    4. Click Save

CALENDLY INTEGRATION:
    1. Embed Calendly inline widget on /contact page
    2. Add Calendly popup link to header navigation
    3. Use Calendly's provided embed code
    4. Test booking flow on mobile and desktop

CREATING PRIVACY POLICY:
    1. Create new page at /privacy-policy
    2. Use Squarespace privacy policy template as starting point
    3. Customize for your specific data practices
    4. Add link in footer (appears on all pages)
